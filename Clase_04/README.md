## Clase 04 — Simulación de un Proceso AR(1)

**Tema:** Sección 3.a del temario: Procesos Autoregresivos AR(p)
**Datos:** No se usan datos externos (proceso simulado, T=1000)
**Paquetes principales:** `ggplot2`, `dplyr`, `latex2exp`

### Objetivos
- Simular un AR(1) y verificar sus propiedades de estacionariedad
- Comparar la FAC teórica (ρ_k = a₁ᵏ) con la FAC muestral
- Entender el rol del parámetro a₁ en la memoria y velocidad de convergencia
