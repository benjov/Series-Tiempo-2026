## Clase ToolBox — Entorno de trabajo y herramientas

**Tema:** R, RStudio, R Markdown, Google Colab y LLMs como herramientas del econometrista
**Datos:** No se usan datos externos
**Paquetes principales:** `rmarkdown`, `openai`

### Objetivos
- Configurar y usar el entorno R + RStudio
- Producir documentos reproducibles con R Markdown
- Conocer alternativas en la nube (Google Colab) y el uso de LLMs (GPT) desde R
