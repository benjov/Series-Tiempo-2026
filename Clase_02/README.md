## Clase 02 — Simulación de Procesos Estocásticos

**Tema:** Sección 1 del temario: La naturaleza de los datos de series de tiempo
**Datos:** No se usan datos externos (procesos simulados)
**Paquetes principales:** base R, `shiny`

### Objetivos
- Simular y graficar ruido blanco y caminatas aleatorias
- Verificar empíricamente las propiedades de un proceso estacionario
- Introducir la función de autocorrelación (FAC) como herramienta descriptiva
